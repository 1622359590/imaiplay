# ImaiPlay 域名配置指南

本文说明如何让租户通过自己的域名访问学习中心，以及如何保留唯一的总后台入口。

## 1. 域名分工

- 总后台：`play.imai.work/admin/`
- 租户学习中心：`academy.example.com/`
- 租户自定义域名不能访问总后台；`academy.example.com/admin/` 应返回 404。

租户编码仍然是系统内部的唯一标识，但用户通过自定义域名访问时，后端根据请求的 Host 自动识别租户，登录页面不再要求用户填写租户编码。

## 2. DNS 配置

### 使用 A 记录

在租户域名服务商处添加：

```text
类型：A
主机记录：academy
记录值：120.25.77.204
```

最终域名为 `academy.example.com`。

### 使用 CNAME 记录

CNAME 的目标必须是域名，不能直接填写 IP。可以配置：

```text
类型：CNAME
主机记录：academy
记录值：play.imai.work
```

DNS 生效后检查：

```bash
dig +short academy.example.com
```

## 3. 宝塔站点与反向代理

在宝塔中为域名添加站点或绑定域名：

```text
academy.example.com
```

反向代理目标保持为：

```text
http://127.0.0.1:18080
```

转发时必须保留原始 Host，Nginx 配置至少包含：

```nginx
proxy_set_header Host $http_host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
```

ImaiPlay 后端会优先使用 Host 查询租户的 `custom_domain`，找不到时才使用子域名或 `X-Tenant-Code`/`X-Tenant-ID` 兼容路径。

## 4. 管理后台限制

只有 `play.imai.work` 提供管理后台：

```nginx
location = /admin {
    if ($host != play.imai.work) { return 404; }
    return 301 /admin/;
}

location /admin/ {
    if ($host != play.imai.work) { return 404; }
    alias /usr/share/nginx/html/admin/;
    index index.html;
    try_files $uri $uri/ /admin/index.html;
}
```

租户域名的根路径指向 PC 学员端：

```nginx
root /usr/share/nginx/html/pc;

location / {
    try_files $uri $uri/ /index.html;
}
```

修改 Docker 内部 Nginx 配置后重新构建：

```bash
docker compose -f docker-compose.bt.yml up -d --build --remove-orphans
```

## 5. HTTPS 证书

在宝塔 SSL 页面为每个租户域名申请 Let's Encrypt 证书，或使用泛域名证书：

```text
*.example.com
```

申请证书前确保 DNS 已生效，并且 80/443 端口可以从公网访问。证书配置完成后开启强制 HTTPS。

## 6. 验证清单

```bash
curl -I https://academy.example.com/
curl -I https://academy.example.com/admin/
curl -I https://play.imai.work/admin/
```

预期结果：

- `academy.example.com/`：返回租户学习中心
- `academy.example.com/admin/`：404
- `play.imai.work/admin/`：返回总后台登录页
- 自定义域名登录：只需手机号/邮箱和密码
