# ImaiPlay 域名配置指南

每个租户开通后都会自动获得默认学习门户，自定义域名只是可选的品牌增强功能。本文同时说明默认入口、自定义域名绑定和唯一总后台入口。

## 1. 域名分工

- 统一登录：`https://play.imai.work/login`
- 总后台：`https://play.imai.work/admin/`
- 默认租户门户：`https://play.imai.work/t/{tenantCode}`
- 可选自定义域名：`https://academy.example.com/`
- 租户自定义域名不能访问总后台；`academy.example.com/admin/` 应返回 404。

客户无需购买域名即可使用默认门户，并可在主题设置中修改 Logo、品牌色和欢迎语。绑定自定义域名后，默认门户和自定义域名会同时有效，并解析到同一个不可变租户 ID。用户在门户登录时不需要填写租户编码。

同一邮箱或手机号属于多个企业时，用户可从统一登录入口输入一次账号密码；密码验证成功后，系统才显示可进入的企业供选择。

## 2. 默认门户（无需配置）

租户注册成功页和管理后台「域名设置」都会显示默认门户。复制该地址即可发给学员：

```text
https://play.imai.work/t/{tenantCode}
```

例如租户编码为 `acme`，入口就是 `https://play.imai.work/t/acme`。只有需要使用企业自有域名时，才继续下面的自动绑定步骤。

## 3. 可选：开启自动绑定

在宝塔面板打开「面板设置 → API 接口」，启用 API 并生成 API Key。然后在服务器项目的 `.env` 中配置：

```dotenv
BAOTA_PANEL_URL=http://host.docker.internal:8888
BAOTA_API_KEY=替换为宝塔生成的APIKey
BAOTA_SERVER_IP=120.25.77.204
BAOTA_PROXY_TARGET=http://127.0.0.1:18080
BAOTA_TLS_INSECURE_SKIP_VERIFY=false
```

这里的端口要换成你的真实宝塔面板端口。后端运行在 Docker 容器中时，
不能填写 `127.0.0.1`（它会指向容器自身）；项目已为容器配置
`host.docker.internal` 主机网关。还需要在宝塔 API 白名单中允许服务器
本机或 Docker 网桥来源地址。

修改配置后重建后端容器：

```bash
docker compose -f docker-compose.yml -f docker-compose.bt.yml up -d --build --remove-orphans
```

`BAOTA_PROXY_TARGET` 是宿主机宝塔 Nginx 转发到 ImaiPlay 的地址。本项目
`docker-compose.bt.yml` 把容器端口映射到宿主机 `127.0.0.1:18080`，
因此线上使用上述默认值；如果你的后端直接监听宿主机 8080，则改为
`http://127.0.0.1:8080`。

如果同机宝塔面板使用自签 HTTPS 证书，可将
`BAOTA_TLS_INSECURE_SKIP_VERIFY` 设为 `true`。该开关只影响宝塔 API 客户端，
但会跳过证书身份校验；应优先配置有效证书，且不要用于不可信的远程面板。

宝塔客户端按现行官方接口向 `{BAOTA_PANEL_URL}/site`、`/data` 和
`/acme` 发送 `application/x-www-form-urlencoded` POST 请求。每次请求携带：

```text
request_time = 当前 Unix 秒时间戳
request_token = md5(request_time + md5(BAOTA_API_KEY))
action = 对应操作名
```

当前参数以宝塔面板 v11.7 官方 API 文档为基准。宝塔官方说明接口可能随
面板版本变化；如果服务器上的面板版本较旧，应先升级面板，或根据该版本
返回的明确参数错误调整对应 action/字段，不能把 API Key 写入代码或日志。

## 4. 租户只需配置 DNS

### 使用 A 记录

在租户域名服务商处添加：

```text
类型：A
主机记录：academy
记录值：120.25.77.204
```

最终域名为 `academy.example.com`。

### 使用 CNAME 记录

CNAME 的目标必须是域名，不能直接填写 IP。可以配置：

```text
类型：CNAME
主机记录：academy
记录值：play.imai.work
```

DNS 生效后检查：

```bash
dig +short academy.example.com
```

租户管理员随后在「域名设置」中依次点击「验证域名」和「自动绑定」。系统会自动：

1. 查询 CNAME 和 A/AAAA 解析，确认最终解析包含 `BAOTA_SERVER_IP`。
2. 在宝塔创建站点。
3. 添加到 `BAOTA_PROXY_TARGET` 的反向代理。
4. 读取宝塔生成的站点 Nginx 配置，写入禁止 `/admin` 的规则，回读确认后执行 Nginx 配置检查与平滑重载。
5. 创建 HTTP 验证的 Let's Encrypt ACME 订单，轮询部署并检查证书状态。
6. 成功后才写入租户 `custom_domain`；中途失败会删除已创建站点。

ImaiPlay 后端会优先使用 Host 查询租户的 `custom_domain`；平台默认门户由路径中的租户编码设置 `X-Tenant-Code`。兼容接入仍可使用子域名或可解析的 `X-Tenant-ID`。所有受保护业务请求还会校验当前门户与 JWT 中的 `tenant_id` 一致。

## 5. 自动配置的管理后台限制

只有 `play.imai.work` 提供管理后台。自动绑定时会为租户站点写入：

```nginx
location ^~ /admin {
    return 404;
}
```

## 6. HTTPS 证书

系统通过宝塔为每个租户域名申请 Let's Encrypt 证书。申请前必须确保 DNS
已经生效，并且 80/443 端口可从公网访问。证书部署到宝塔站点后由宝塔的
证书管理任务负责自动续期，无需租户上传证书；运维人员应在宝塔的 SSL
证书列表中确认自动续签任务已开启，并定期检查续期失败告警。

## 7. 解绑

租户管理员点击「解绑」后，系统先删除对应宝塔站点，再清空
`custom_domain`，并记录审计日志。删除站点失败时不会清除数据库中的域名，
方便排查后重试。解绑不会影响默认门户，学员仍可通过 `/t/{tenantCode}` 访问。

## 8. 验证清单

```bash
curl -I https://academy.example.com/
curl -I https://academy.example.com/admin/
curl -I https://play.imai.work/admin/
curl -I https://play.imai.work/t/acme
```

预期结果：

- `academy.example.com/`：返回租户学习中心
- `academy.example.com/admin/`：404
- `play.imai.work/admin/`：返回总后台登录页
- `play.imai.work/t/acme`：返回同一租户的默认学习门户
- 自定义域名登录：只需手机号/邮箱和密码
