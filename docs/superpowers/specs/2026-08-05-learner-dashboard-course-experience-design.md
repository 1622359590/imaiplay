# 学员学习中心与站长管理后台设计

## 目标

以用户提供的三张学员端截图和两张站长后台截图为视觉与交互目标，把当前极简学员端与后台升级为完整、真实数据驱动的学习和运营工作台：

- 首页展示必修课程完成数、今日与累计学习时长。
- 支持全部、必修、选修、已学完、未学完和课程分类筛选。
- 课程卡展示课程属性、完成状态或真实课程进度。
- 课程详情展示课程总体进度、课时完成状态、续学位置和课程附件。
- 顶栏恢复“首页 / 最近学习”，最近学习按课程去重并能继续上次课时。
- 管理后台能够配置课程分类、给学员分配必修或选修课程，并维护课程附件。
- 站长后台采用参考图的浅色工作台、可展开分组侧栏和真实运营数据，并按现有角色权限显示不同菜单。

所有统计与状态必须来自后端，不在前端伪造示例数字。租户 Logo、品牌文字和主色继续使用当前租户配置，截图中的 `IMAI.WORK`、珊瑚红和示例课程内容只作为布局与视觉参考，不写死到业务数据中。

还原原则：

- 使用白色页面、浅灰边界、柔和阴影和租户主色强调，保持截图的轻量企业学习风格。
- 顶栏、统计卡、筛选栏、课程卡、详情卡和内容列表共享同一条居中内容边界。
- 桌面公共容器最大宽度为 1600px；宽屏保留对称留白，普通桌面保留 24px 安全边距。
- 首页统计卡使用两列；课程网格宽屏三列、常规桌面两列、窄屏一列，课程不足一行时从左侧开始排列。
- 课程详情头图为横向信息卡：封面和说明在左，总体进度环在右；窄屏改为上下结构。
- “课程目录 / 课程附件”使用可键盘操作的标签页，当前项使用租户主色和短弧形下划线。
- 使用现有 Ant Design 与 `@ant-design/icons`。它与参考图的线性图标风格一致，不引入第二套图标库，不绘制自定义 SVG、CSS 图标或占位插画。
- 课程封面继续使用真实课程图片；无封面时使用现有品牌色与书本图标，不生成虚构课程封面。
- 课时播放器继续保持 `max-width: 1000px` 并在公共容器左侧对齐，不能重新引入此前修复过的额外居中偏移。
- 站长后台复用参考图的白色侧栏、浅灰工作区、两列运营卡片和珊瑚色激活态，但品牌、菜单和指标必须使用 ImaiPlay 当前租户配置与真实能力。

## 方案选择

采用方案 A：完整还原五张截图的信息结构和视觉，并补齐后端数据、管理入口与权限。这是用户已选择的方案，也是唯一能让统计、筛选、进度、附件和站长运营数据长期正确工作的方案。

未采用方案 B：只做前端截图复刻并使用推断数据。它上线快，但会再次出现虚假的完成数、进度和学习时长。

未采用方案 C：只把附件插入当前极简页面。它不能满足用户明确要求的首页统计、筛选、详情状态和最近学习体验。

后台采用方案 D：单一管理应用、按角色生成不同的分组菜单和首页。这能复用现有路由、权限与组件，同时让站长获得参考图中的完整工作台体验。

未采用方案 E：逐项复制 PlayEdu 的部门、产品文档和许可菜单。当前系统没有部门与文档中心模型，照搬只会产生空入口和虚假数据。

未采用方案 F：为站长另建一套独立后台。它会复制登录、主题、课程和资源管理逻辑，增加权限漂移与长期维护成本。

## 学员端信息架构与路由

- `/`：学习首页，包含统计、筛选和课程列表。
- `/recent`：最近学习，按课程去重，按最后学习时间倒序。
- `/courses`：兼容旧入口，重定向到 `/`。
- `/courses/:courseId`：课程详情，包含课程目录和课程附件两个标签页。
- `/courses/:courseId/lessons/:lessonId`：课时学习，保留当前播放器与文档打开能力。

顶栏左侧显示租户品牌，中间显示“首页 / 最近学习”，右侧显示“学员”身份入口和退出操作。当前路由使用租户主色标记；小屏允许导航紧凑显示，不能遮挡品牌或退出操作。

## 首页

### 统计区

“课程进度”卡展示：

- `必修课：已学完课程 X / Y`
- `Y` 只统计当前用户有效分配、当前可访问且类型为 `required` 的课程。
- 零课时课程不算完成。

“学习时长”卡展示：

- 今日有效学习分钟数。
- 累计有效学习分钟数。
- 不足一分钟显示 `0 分钟`；超过 60 分钟仍以总分钟显示，和参考图一致。

### 筛选区

左侧互斥筛选：

- 全部
- 必修课
- 选修课
- 已学完
- 未学完

右侧分类下拉默认为“所有分类”。分类选项由当前课程集合去重生成。类型/完成状态和分类可以组合；切换筛选不重新加载整页。

“未学完”同时包含未开始和学习中。无匹配课程时显示明确空状态，并保留当前筛选供用户调整。

### 课程卡

- 有封面时展示 4:3 左侧封面；无封面时正文使用完整宽度。
- 展示课程名称以及“必修课”或“选修课”标签。
- 100% 完成时显示完成奖章图标和“恭喜你学完此课程！”。
- 未完成时显示进度条和整数百分比。
- 整张卡可点击并支持 Enter/Space 键进入详情。

## 最近学习

- 每门课程只出现一次，取该课程最近更新的课时进度。
- 按 `last_learned_at` 倒序。
- 卡片显示课程总体进度、最近课时名称和“继续学习”。
- “继续学习”进入最近课时，并由播放器恢复 `last_position_seconds`。
- 无记录时显示“还没有学习记录，去首页选择课程吧”。

## 课程详情

### 课程概览卡

- 封面、课程名称、必修/选修标签和课程说明。
- 课程说明继续使用现有 `description`；不新增截图中没有独立管理入口的“适合人群/课程目标”字段。
- 完成后显示祝贺文案；未完成时显示“已完成 A / B 个课时”。
- 右侧进度环展示 0–100 的课程总体进度。

### 课程目录标签

- 按章节顺序展示章节标题和课时。
- 课时展示名称与真实时长。
- 状态为完成时显示“已学完”。
- 状态为学习中时显示“上次学习到 mm:ss”和“继续学习”。
- 状态为未开始时显示“开始学习”。
- 点击整行或操作文字进入对应课时。
- 课程无章节或课时时显示空状态；零课时课程进度固定为 0。

### 课程附件标签

- 有资料时展示文件图标、显示名称和下载操作。
- 长名称单行省略，悬停可查看完整名称。
- 下载按钮显示进行中状态；失败时在当前页面提示，不跳转到空白页。
- 无资料时标签仍可见，并显示“暂无课程附件”，让用户明确知道课程没有资料。

附件管理复用主线已完成的课程资料能力：PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、ZIP，单文件最大 200MB。管理后台支持上传、重命名、排序、替换和删除；学员接口只返回安全元数据，不返回存储 URL、租户 ID 或创建人。

## 站长管理后台

### 角色映射

用户所说的“站长”映射到现有后端角色 `tenant_admin`，界面文案显示为“站点管理员”或简称“站长”，不修改数据库角色枚举。

管理应用继续支持三类后台角色：

| 角色 | 首页 | 可见能力 |
| --- | --- | --- |
| `superadmin` | 平台概览 | 租户、套餐、官方课程、全平台账号、平台配置、审计 |
| `tenant_admin` | 站点概览 | 学员、课程、官方课程、资源、分类、主题、域名、审计、套餐与存储用量 |
| `instructor` | 教学工作台 | 自己管理的课程、允许使用的资源；不显示学员、站点设置、审计和套餐 |

前端隐藏菜单只负责体验，后端仍按角色逐接口校验。未知角色没有后台访问权限。

### 后台壳与分组侧栏

- 参考图按约 2 倍像素密度换算后，顶栏桌面高度为 48px，侧栏宽度为 200px，背景均为白色；不能把截图原始像素直接当作 CSS 像素。
- 左上使用租户 `logo_url` 和租户名称；未配置 Logo 时使用现有 ImaiPlay 品牌标记，不复制参考图的 `PLAYEDU` Logo。
- 顶栏右侧显示真实账号姓名、角色中文名和头像菜单；页面刷新后仍要恢复用户资料，不能长期显示通用“管理员”。
- 工作区使用 `#f6f6f6` 附近的浅灰背景，外边距与网格间距均为 24px；卡片使用白底、约 12px 圆角和极轻阴影。
- 当前租户主色作为选中菜单、按钮和焦点色；参考图的珊瑚红只在租户未配置主色时作为后台默认色。
- 一级菜单有图标、文字和展开箭头；父项只负责展开或收起，不导航。二级菜单缩进显示，整行点击高度为 44–48px。
- 多个分组可以同时展开，不使用单开手风琴；站长首次进入默认展开参考图二中的业务分组，当前路由所属分组始终自动展开。
- 用户主动展开或收起的状态存入 `sessionStorage`，刷新时恢复；当前路由优先级高于保存状态，不能出现选中子项被折叠隐藏。
- 侧栏收起后只显示一级图标，带二级菜单的项目通过悬浮弹层访问；不能把子菜单直接丢失。
- 侧栏内容独立纵向滚动，Logo 区保持可见；主内容滚动不能带走导航定位。
- 960px 以下改为抽屉侧栏，内容区不保留固定的 76px 空白列。
- 参考默认主色为 `#ff4e4f`；需要白字的激活菜单使用达到文字对比度要求的深色衍生值，不能为了逐像素复刻牺牲可读性。

站长侧栏分组：

- 首页概览
- 资源管理
  - 资源列表
  - 资源分类
- 课程中心
  - 课程管理
  - 官方课程
- 学员管理
  - 学员与成员
- 站点设置
  - 主题设置
  - 域名设置
- 安全审计
  - 审计日志

课程附件在具体课程内容页维护，不新增孤立的“附件管理”菜单。当前系统没有部门模型，因此不显示参考图中的“部门”；需要组织架构时另行设计，不能用资源分类冒充部门。

总管理员侧栏分组：

- 平台概览
- 租户运营
  - 租户管理
  - 套餐管理
- 内容中心
  - 官方课程
  - 全平台账号
- 平台配置
  - 短信服务
  - 存储服务
  - 审计日志

讲师侧栏分组：

- 教学工作台
- 课程中心
  - 我的课程

  - 资源列表

讲师可以上传和读取本租户教学资源，但不能删除共享资源、维护资源分类或修改站点配置。

| 课程管理 / 我的课程 | `/courses` |

资源的“视频 / 图片 / 文档 / 附件”是 `/resources` 页内的类型筛选，不伪造成没有独立业务能力的侧栏页面。

### 站点概览

站长首页按参考图使用两列等宽工作台。桌面卡片横纵间距均为 24px，第一行约 142px、第二行约 176px，第三行按内容自适应且最小约 376px。所有卡片在同一网格内对齐，空状态在卡片内居中表达，不渲染只有序号或图例的占位内容。

顶部左侧指标卡：

- 今日学习学员，并显示相对昨日的增减人数。
- 学员总数，并显示今日新增人数。
- 已发布课程数，并附课程总数。

顶部右侧指标卡：

- 资源分类数。
- 资源总数。
- 管理成员数，统计当前租户有效的 `tenant_admin` 与 `instructor`。

第二行左侧“快捷操作”：

- 添加学员：进入用户管理并自动打开新增表单。
- 新建课程：进入课程管理并自动打开新建表单。
- 上传资源：进入资源管理并自动打开上传区。
- 管理官方课程：进入官方课程启用页面。

第二行右侧使用“站点与套餐”卡替代参考图中当前系统不存在的“产品文档”：

- 当前套餐名称。
- 存储已用量 / 配额与进度条。
- 当前绑定域名或租户访问地址。
- 进入主题设置、域名设置或资源管理的真实链接。

第三行左侧“今日学习排行”：

- 使用本次新增的真实学习时长日报，按今日有效学习秒数降序展示前 10 名。
- 展示排名、学员姓名、学习分钟数；前三名使用图标与文字共同区分。
- 无学习记录时显示空状态，不渲染只有序号的占位榜单。

第三行右侧“资源统计”：

- 使用真实资源数量绘制环形图。
- 类型分为视频、图片、文档、课程附件；为 0 的类型保留图例但不绘制无意义扇区。
- 圆心显示资源总数，外侧或图例同时显示每类数量，不能只依赖颜色。
- 使用维护中的图表库实现，不用 `conic-gradient`、手写 SVG 或 CSS 图形模拟数据图表。
- 图表色默认使用视频 `#fe8650`、图片 `#ffb501`、文档 `#00cc66`，课程附件使用租户主色的可区分衍生色；Tooltip、图例、键盘说明和窄屏布局都要完整。

“清除演示数据”不再占据工作台主视觉。只有后端确认当前租户仍存在初始化演示数据时，它才出现在站点与套餐卡的次要危险操作区；仍需二次确认并明确不可撤销。

### 平台概览与教学工作台

总管理员保留现有平台指标和最近租户，但套用同一浅色卡片与分组侧栏。平台概览不展示单个租户的快捷操作、资源分类或域名配置。

讲师首页只展示本人课程总数、已发布课程、今日学习自己课程的学员数和最近编辑课程。统计必须按 `created_by` 或明确的授课关系过滤，不能继续暴露整个租户的运营数据。

### 现有管理页面一致化

- 页面标题、工具栏、筛选区、表格、分页、空状态和弹窗统一使用新的浅色管理规范。
- 用户管理在站长语境中标题显示为“学员与成员”，保留学员、讲师和站点管理员角色维护。
- 课程列表增加课程分类；课程内容页增加学员分配类型和课程附件管理。
- 资源列表支持图片、视频、PDF 与通用课程附件，类型标签与资源统计使用同一口径。
- 所有快捷操作通过明确路由状态或查询参数打开目标表单；刷新页面后不会重复提交。
- 路由守卫与菜单角色使用同一份角色配置，避免“菜单看得到、点击后被 403”或“路由可访问但菜单隐藏”。

## 数据模型

### 课程分类

在 `courses` 增加可空 `category` 字段并建立索引。首期使用短文本，避免为只有单级下拉的需求提前引入分类树。

### 分配类型

在 `course_enrollments` 增加 `assignment_type`：

- `required`：必修
- `optional`：选修

现有报名数据迁移后默认为 `required`。必修/选修属于“某个学员与某门课程的关系”，不能放在课程全局字段，否则同一课程无法对不同学员采用不同要求。

### 学习时长

新增按自然日累计的学习时长记录，至少包含：

- `tenant_id`
- `user_id`
- `study_date`，按租户默认时区 `Asia/Shanghai` 计算
- `duration_seconds`
- 唯一约束 `(tenant_id, user_id, study_date)`

另建轻量上报回执记录，至少保存 `tenant_id`、`user_id`、`lesson_id`、`report_id`、`watched_seconds_delta` 和创建时间，并对 `(tenant_id, user_id, report_id)` 建唯一约束。日报累加与回执写入必须在同一事务中完成，才能在请求超时重试时保持幂等。

播放器只在真实播放时累计秒数，每 15 秒及暂停、结束、离开页面时上报 `watched_seconds_delta` 和唯一 `report_id`。后端校验有效报名，单次有效增量限制为 1–60 秒，使用 `report_id` 幂等去重后再累加。拖动播放位置、暂停和后台挂起不计入观看时长，重复请求不重复累计。

该日报同时是站长“今日学习排行”、今日/昨日活跃学员和总学习时长的唯一统计来源。为站长聚合增加 `(tenant_id, study_date, duration_seconds)` 索引；排行只连接当前租户、角色为 `learner` 且有效的用户。

### 后台聚合口径

- 学员总数只统计当前租户 `role=learner AND status=1`，不把站长和讲师算作学员。
- 今日新增学员只统计按 `Asia/Shanghai` 自然日创建的有效学员。
- 今日/昨日学习学员只统计对应日报中 `duration_seconds > 0` 的有效学员；增减值为今日人数减昨日人数。
- 管理成员数只统计当前租户有效的 `tenant_admin` 和 `instructor`。
- 站点课程总数包含租户自建课程和已启用的官方课程；已发布课程数只统计当前学员实际可见的已发布课程。
- 资源总数和视频、图片、文档、附件分项都按 `resources.resource_type` 统计，圆环中心总数必须等于各分项之和。具体课程挂载附件的数量另按 `course_materials` 统计，不能混入资源总数造成重复。
- 所有站长聚合都强制使用当前 `tenant_id`；讲师聚合额外按 `created_by` 或明确授课关系收窄。
- 旧版 `total_learning_seconds` 不再对 `last_position_seconds` 求和，而从日报累计；旧版课程完成率如为兼容而保留，必须以“已完成有效报名数 / 有课时的有效报名数”计算，站长新首页不依赖该字段。

## 课程进度口径

- 单课时进度继续使用现有 `progress_percent`，限制在 0–100。
- 课程总体进度为所有课时百分比的算术平均值，未产生记录的课时按 0；最终取四舍五入整数。
- 课程至少有一个课时且所有课时状态均为完成，才算已学完。
- 零课时课程进度为 0，不算已学完。
- 最近课时取该课程内 `updated_at` 最新的进度记录。
- 必修完成数只统计当前用户有效报名、课程已发布、租户可见且 `assignment_type=required` 的课程。

## API

### 学员首页

`GET /api/v1/learner/overview`

一次返回：

- `required_completed`
- `required_total`
- `today_learning_seconds`
- `total_learning_seconds`
- `categories`
- 当前用户有效报名课程的摘要列表：课程基础信息、分配类型、课时数、已完成课时数、课程进度、最后学习时间、最近课时。

首页筛选在前端对这一份数据执行，避免切换标签时重复请求。

### 课程详情

`GET /api/v1/courses/:id` 只允许当前用户有效报名且当前租户可访问的课程，并返回：

- 课程、章节、课时。
- 分配类型与课程总体进度。
- 每个课时的进度、状态和上次播放位置。
- 安全的附件元数据。

### 进度与最近学习

- `POST /api/v1/lessons/:id/progress` 增加 `watched_seconds_delta` 和 `report_id`，旧客户端不传时仍可更新播放位置和百分比，但不累计学习时长。
- `GET /api/v1/recent-learning` 改为课程级去重结果，供 `/recent` 页面使用。

### 管理后台

- 课程创建/编辑支持 `category`。
- 报名创建支持 `assignment_type`，并增加更新分配类型接口。
- 课程内容页增加学员分配管理和课程附件管理。
- `GET /api/v1/auth/me` 返回当前登录用户的安全资料；密码和验证码登录也返回同一份 `user`。管理端启动时用它恢复姓名与角色，不从 JWT 猜姓名。
- `GET /backend/v1/dashboard` 保留原路径，按角色返回带 `scope` 的数据：`platform`、`tenant` 或 `instructor`。站长数据至少包含：
  - `today_learning_user_count`
  - `yesterday_learning_user_count`
  - `today_learning_user_delta`
  - `learner_count`
  - `today_new_learner_count`
  - `published_course_count`
  - `course_count`
  - `resource_category_count`
  - `resource_count`
  - `manager_count`
  - `has_demo_data`
  - `resource_type_counts`，固定返回 `video`、`image`、`document`、`attachment`
  - `today_learning_ranking`，每项只返回学员 ID、显示名和有效学习秒数，最多 10 条
- 站点与套餐卡复用 `GET /backend/v1/plan/current`、现有主题和域名接口；页面并行加载，单个次要接口失败时只降级对应卡片，不让整个工作台白屏。
- 快捷入口使用一次性查询参数：`/users?create=1`、`/courses?create=1`、`/resources?upload=1`。目标页消费并清除参数后打开对应表单，刷新不会重复打开或提交。
- 课程与资源接口为讲师增加明确的最小能力：只读/维护本人课程；可列出和上传本租户教学资源，但不可删除共享资源、维护分类或管理课程附件。站长保留完整管理能力。

## 权限与安全

- 学员课程列表、详情、课时资源、进度上报和附件下载统一要求有效报名。
- 租户自建课程必须属于当前租户且已发布。
- 官方课程必须已发布、当前租户已启用，并且当前学员有效报名。
- 跨租户、未报名、资料与课程不匹配统一返回 404，避免泄露资源存在性。
- 附件详情 DTO 只返回 `id`、`display_name`、`resource_type` 和 `size_bytes`。
- 学习时长上报限制单次增量并幂等去重，不能通过重试放大时长。
- 后台菜单和路由守卫从同一份角色配置生成；每个页面显式声明允许的角色，不能再把所有非 `superadmin` 用户当成站长。
- `instructor` 直达用户、官方课程、资源分类、主题、域名、审计、套餐和平台配置路由时返回无权限页，不发起对应业务请求。
- `tenant_admin` 不能访问租户、套餐写操作、短信和平台存储配置；`superadmin` 不能借空租户上下文读取任一租户的站点聚合。
- 后台资料接口不返回密码哈希、刷新令牌或其他租户的资料；禁用账号和过期会话沿用现有安全会话校验并退出到登录页。

## 状态与错误处理

- 首页统计和课程列表共享一次加载骨架，加载失败显示重试入口。
- 课程详情失败时区分不可访问与网络失败；两者都保留返回首页入口。
- 单个附件下载失败不影响目录和其他附件。
- 学习时长心跳失败时保留待上报秒数，在后续心跳合并重试；视频播放不被阻断。
- 进度上报失败继续保持当前非阻塞体验，但离开页面前强制尝试最后一次上报。
- 所有百分比在前后端边界都限制到 0–100。
- 站长工作台的主指标加载失败时显示整卡重试；套餐、域名或图表等次要区域失败时各自显示小型重试，不清空已成功的指标。
- 排行与资源图表对空数据展示明确空状态；图表库加载失败时退化为带数量的文本列表，而不是隐藏数据。
- 用户资料恢复期间顶栏显示骨架；401/403 使用统一会话或权限页面，动态分包失效继续使用现有自动刷新恢复与友好错误页。

## 响应式与无障碍

- 1600px 以上：最大宽度容器、三列课程卡。
- 960–1599px：两列课程卡；统计卡仍两列。
- 760px 以下：统计卡、详情概览和课程卡改为单列；标签允许横向滚动。
- 所有可点击卡片、标签、课时行和下载按钮可键盘聚焦。
- 进度不能只用颜色表达，同时显示数字或状态文字。
- 主色、正文和浅色背景达到可读对比度；尊重 `prefers-reduced-motion`。
- 管理后台 1200px 以上使用 200px 固定侧栏和两列工作台；960–1199px 侧栏可收至 76px，工作台改为单列；960px 以下使用抽屉侧栏。
- 管理后台 640px 以下指标换为两列流式布局、快捷操作为 2×2，排行改单列；环图隐藏外侧引导线但保留中心总数和文字图例。
- 侧栏父项、子项、快捷入口和图表替代说明均支持键盘与可见焦点；菜单选中态、排行名次和资源类型不能只依赖颜色表达。

## 实施策略

当前分支从主线共同基线 `72c6723` 分叉，主线 `97fee3e` 已包含经过测试的附件全栈。实现时先在隔离工作树中合并主线，再解决三个已确认的提交树冲突：

- 保留管理后台的动态分包失效恢复。
- 保留课时播放器在公共容器内左对齐的修复。
- 保留主线课程附件、官方课程、播放器安全和珊瑚色界面更新。

随后在合并后的代码上增加学员聚合、时长心跳、分配类型、分类和截图界面，避免在旧模型上重复实现附件链路。原工作区已有未提交文件不进入本功能提交，也不能被覆盖。

后台实现以主线已有的白色侧栏、珊瑚色管理样式、安全会话、官方课程、上传预览、主题与域名管理为基线，再把静态 `type: group` 菜单改为真正的可展开子菜单。动态分包失效恢复、角色/租户/过期校验不能在合并或布局重构中回退。图表依赖在实现阶段选用与当前 React 和 Ant Design 版本兼容、仍在维护的现成库，并把依赖锁文件纳入同一功能提交。
