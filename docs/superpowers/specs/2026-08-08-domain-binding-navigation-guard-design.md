# 域名绑定期间离开保护设计

## 目标

租户管理员启动自定义域名自动绑定后，明确告知配置仍在进行，并避免其误点侧边栏、浏览器返回、刷新或关闭页面而中断观察流程。

## 交互方案

当域名状态为 `creating_site` 或 `configuring` 时，域名设置页显示不可手动关闭的等待弹窗：

- 标题：`正在配置自定义域名`
- 正文：`系统正在创建站点、配置访问并申请 HTTPS 证书，请勿关闭、刷新或离开当前页面。`
- 辅助说明：`通常需要 1–3 分钟，完成后页面会自动更新。`
- 显示当前步骤名称与整体进度。
- 不提供取消或关闭按钮，禁止点击遮罩或按 Esc 关闭。

弹窗遮罩阻止用户误点页面内导航。绑定成功或失败后，弹窗自动消失，现有成功或失败提示继续显示。

## 离开保护

绑定进行中：

- 浏览器刷新、关闭标签页或跳转到站外地址时，使用浏览器原生离开确认。
- React Router 页面内跳转和浏览器返回操作被拦截，保持在域名设置页。

绑定结束后立即解除所有离开保护，正常恢复导航。

DNS 验证状态 `pending_verification` 不启用强制等待弹窗，因为该请求时间短；离开保护仅针对已经启动的站点创建和证书配置流程。

## 状态与数据流

页面继续使用现有 1.5 秒轮询更新 `DomainBindStatus`。等待弹窗完全由服务端状态驱动，因此刷新后若绑定仍在进行，重新获取状态后会再次显示。

进度取值继续使用：

`current_step / total_steps`

步骤标题复用现有 `flowSteps`，避免弹窗与页面下方进度说明不一致。

## 异常处理

- 短暂状态查询失败时不解除等待弹窗，避免用户误以为配置已结束。
- 服务端明确返回 `ready`、`setup_failed` 或其他非工作状态后解除保护。
- 页面卸载时清理 `beforeunload` 监听，避免影响后台其他页面。

## 测试标准

- `creating_site` 与 `configuring` 状态会启用等待和离开保护。
- `pending_verification`、`ready`、`setup_failed` 不启用保护。
- 工作状态下展示正确的步骤文本和百分比。
- 前端 TypeScript 检查、单元测试和生产构建通过。

## 范围限制

本次不增加后台任务中心、取消绑定按钮或跨设备通知；域名绑定服务端流程保持不变。
