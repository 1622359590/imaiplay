# PlayEdu 风格界面重设计

## 目标

在不改变现有 API、权限、路由行为和数据模型的前提下，将管理后台与 PC 学员端统一为 PlayEdu 风格的浅色企业学习界面：白色工作区、珊瑚红品牌强调色、清晰的卡片层级和较宽松的内容留白。

## 范围

### Admin 阶段

- `AdminLayout`：保持现有角色菜单过滤和路由键，重做为白色固定侧栏、珊瑚红激活态、品牌播放图标和简洁顶栏。
- `Dashboard`：保留现有真实统计 API；将平台概览和租户看板分别映射到 PlayEdu 风格统计卡片、快捷入口和运营区块。接口没有提供的部门、管理员、资源分布等指标不改后端，使用明确的空值/占位展示。
- `styles.css`：建立浅色 admin token、侧栏/顶栏/卡片/统计网格/响应式断点样式，移除深色玻璃视觉。
- `Login`：改为浅色页面和居中白色登录卡片，保留租户编码兼容逻辑、密码登录和动态错误处理。

### PC 学员端阶段

- `AppLayout`：保留租户主题 Logo、门户名称、登出和门户路由，增加首页/最近学习导航、部门或门户信息和用户身份区。
- `HomePage`：保留课程 API 和加载/空状态；增加课程进度摘要、学习时长摘要的可用数据展示、客户端筛选标签和分类筛选。
- `CourseCard` / `styles.css`：改成 PlayEdu 风格横向课程卡片，显示封面、类型标签、学习进度和百分比；无封面时保留可访问的默认图标。
- `LoginPage`：改为浅色居中登录卡片，保留域名/门户识别、邮箱或手机号登录、密码登录和错误提示。

## 设计约束

- 主色使用现有 `#ff5156` 珊瑚红体系，不引入新的样式依赖或图表依赖。
- 图表使用现有 Ant Design/原生 CSS 能力；不修改后端接口来补充设计数据。
- 所有现有请求、角色守卫、租户主题下发、域名门户路由和登录流程保持不变。
- 桌面端采用三列课程网格和响应式降级；小屏侧栏、统计卡片、导航和课程卡片必须可用。
- 管理后台与学员端各自保持现有 token 系统，不互相复用运行时状态。

## 验证方案

1. Admin 阶段完成后运行 `cd web/admin && npm run build`。
2. PC 阶段完成后运行 `cd web/pc && npm run build`。
3. 最终检查登录、角色菜单、课程加载、空状态、课程详情入口、登出和门户路径没有被视觉改造破坏。
