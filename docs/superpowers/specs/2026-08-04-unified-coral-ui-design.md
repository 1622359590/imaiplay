# ImaiPlay 统一浅色珊瑚红界面设计

日期：2026-08-04  
状态：已选定方案 B，待实施计划确认

## 1. 目标

将 ImaiPlay 学院端 PC、学院端 H5、学员登录页和管理后台统一为简洁、清晰的浅色珊瑚红视觉体系，并解决课程详情页内容过宽、封面过大、留白失衡和阴影偏重的问题。

本次只调整现有界面的布局和视觉表现，不新增业务流程、页面路由或数据接口。

## 2. 设计原则

- 简单优先：减少装饰性渐变、光晕、玻璃效果和大面积阴影。
- 清晰优先：正文与背景保持足够对比度，避免浅色文字难以辨认。
- 一致优先：PC、H5、登录页和后台共用同一套基础色彩、圆角和边框规则。
- 紧凑但不拥挤：缩小过大的封面和卡片，保留明确的内容分组与触控空间。
- 保留功能：课程浏览、目录展开、学习、登录、后台导航、表格和表单行为保持不变。

## 3. 视觉变量

| 用途 | 色值 |
| --- | --- |
| 主色 | `#ff5156` |
| 主色悬停 | `#e84349` |
| 主色浅背景 | `#fff1f0` |
| 页面背景 | `#fafafa` |
| 卡片背景 | `#ffffff` |
| 标题 | `#262626` |
| 正文 | `#595959` |
| 次要文字 | `#737373` |
| 分隔线 | `#eeeeee` |

通用规则：

- 主卡片圆角以 10–12px 为主。
- 输入框、按钮和菜单选中态圆角以 8–10px 为主。
- 普通卡片默认不使用大阴影；需要层级时仅使用低透明度短阴影。
- 成功、警告和危险状态继续使用语义色，不强制改成珊瑚红。

## 4. 学院端 PC

### 4.1 全局结构

- 页头、主要内容和页脚使用同一条内容边界。
- 主内容最大宽度约 1080px，两侧保留至少 20px 安全间距。
- 页面垂直间距统一，减少同一页面中 20px、28px、48px 混用的情况。
- 移除旧深色主题遗留的光晕、玻璃背景和紫蓝渐变覆盖。

### 4.2 首页

- 保留现有课程入口和数据逻辑。
- 标题区、课程数量和课程卡片左边界对齐。
- 课程卡片使用白底、浅边框和轻量悬停反馈。
- 无课程封面时使用珊瑚红纯色底和现有图标，不制作新的装饰图案。

### 4.3 课程详情页

- 返回入口与内容卡片对齐。
- 头部课程信息卡使用紧凑双栏：封面约 320px 宽、16:9，右侧信息自适应。
- 双栏间距约 28px，卡片内边距约 24px。
- 标题、描述和课时信息按内容自然排列，消除右侧大面积空白。
- 目录卡片与头部卡片同宽，使用浅边框和低层级阴影。
- 章节行高和课时行高适当收紧，但可点击区域不低于 44px。

### 4.4 学习页

- 视频或文档区域宽度与详情页内容边界一致。
- 学习进度、标题和返回操作沿用统一的珊瑚红强调色。
- 不改变现有播放、进度记录和文档访问逻辑。

## 5. 学院端 H5

- 保留现有单列结构与路由。
- 页头高度、页面内边距、课程卡片、详情卡片和目录卡片统一尺寸节奏。
- 课程详情封面保持 16:9，不使用过高的彩色头图。
- 卡片间距约 12px，页面左右内边距约 14–16px。
- 操作按钮和目录课时点击区域满足移动端触控尺寸。
- H5 在桌面预览时继续保持合理的最大宽度，但不增加手机外壳式装饰。

## 6. 登录页

### 6.1 学员 PC 登录

- 深蓝紫色全屏背景改为 `#fafafa`，可使用极弱的 `#fff1f0` 背景层次，但不使用深色渐变。
- 登录卡片居中，宽度约 400–420px，白底、浅边框、轻阴影。
- 品牌图标、标题、输入框焦点和主按钮使用珊瑚红。
- 标题使用 `#262626`，说明与标签使用 `#595959`/`#737373`。
- 输入框使用白底和可见灰色边框，错误态继续使用 Ant Design 语义样式。

### 6.2 学员 H5 登录

- 与 PC 共用相同的视觉变量。
- 单列卡片适配安全区，避免表单贴边。
- 保留企业 Logo、欢迎文案、忘记密码和登录跳转逻辑。

### 6.3 管理后台登录

- 同样改为浅色背景和白色登录卡片。
- 管理员登录、租户选择、忘记密码和开通租户入口全部保留。
- 租户选择卡片使用浅边框，选中/悬停反馈使用浅珊瑚红。

## 7. 管理后台

### 7.1 框架

- 侧边栏改为白底，右侧使用浅灰分隔线，不再使用紫色深底。
- 品牌标记使用珊瑚红底白色文字或现有真实 Logo。
- 普通菜单为深灰文字；当前菜单为 `#fff1f0` 背景和 `#ff5156` 文字。
- 菜单分组标题使用次要灰色，折叠模式保持可用。
- 顶部栏使用白底和浅灰下边框，头像使用浅珊瑚红背景。

### 7.2 内容区

- 页面背景统一为 `#fafafa`。
- 页面标题、说明、主操作按钮和内容卡片对齐。
- 表格表头使用很浅的灰色或珊瑚红暖灰，不使用蓝紫色。
- 新增、编辑、查看、分页当前项等主要交互使用珊瑚红。
- 删除操作保留危险红，发布状态保留成功绿。
- 课程封面占位、统计图标、上传区域和进度条统一替换旧蓝色视觉。

### 7.3 租户主题职责

- 管理后台框架固定使用本设计的珊瑚红视觉，不随租户主题色改变。
- 现有“主题设置”功能和接口继续保留，用于维护租户门户数据。
- 不在本次视觉改版中改变主题设置的数据模型或权限。

## 8. 响应式规则

- 课程详情页在宽度不足约 900px 时切换为单列。
- 后台在窄屏下保留折叠侧边栏；表格允许现有的水平滚动或响应式列策略。
- 页面最小宽度 320px，不应出现主体内容被固定侧边栏覆盖的情况。
- PC、平板和 H5 均需检查长标题、长企业名、无封面、空目录和表格较宽状态。

## 9. 技术方案

采用方案 B：统一设计变量并针对关键结构做有限调整。

- 学员 PC/H5 继续复用现有 `learnerPalette`，补齐登录与所有简化页面的最终样式覆盖。
- 后台建立对应的珊瑚红变量，并调整 Ant Design `ConfigProvider` 组件令牌。
- 后台框架色与租户门户主题色解耦，避免租户自定义色破坏后台一致性。
- 优先修改现有组件和 CSS，不引入新的 UI 框架，不重写业务组件。
- 清理或覆盖会与浅色主题冲突的深色登录、蓝紫渐变和玻璃效果规则。

## 10. 验收标准

- 学院端 PC：首页、课程详情、学习页和登录页均使用清晰的浅色珊瑚红体系。
- 学院端 H5：首页、课程详情、学习页和登录页视觉一致，320px 宽度下无横向溢出。
- 课程详情页封面不再占据近半以上内容宽度，标题区域无异常大空白。
- 管理后台登录页、侧边栏、顶部栏、卡片、表格和主要操作不再出现旧紫蓝主色。
- 后台侧边栏为浅色，选中菜单可清晰识别。
- 文字对比度清晰，不再出现接近白底的浅色正文。
- 所有现有核心交互与路由保持可用。
- PC、平板和 H5 的构建、类型检查和相关测试通过。
- 在用户当前选择的浏览器中，用相同视口将实现截图与参考截图并排比较，修复明显的间距、裁切、文字、边框和圆角差异。
