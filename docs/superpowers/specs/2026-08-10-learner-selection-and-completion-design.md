# 学员端选中态与完成状态设计

## 目标

统一 PC 学员端顶部导航、首页课程筛选和课程详情标签的选中尺寸，并让最近学习中的已完成课程明确显示完成状态。

## 视觉规则

- 顶部导航、首页筛选、课程详情标签的选中区域统一为 `40px` 高。
- 选中区域统一使用 `10px` 圆角和不少于 `18px` 的左右内边距。
- “课程目录”“课程附件”等四字标签保留自然宽度，但选中区域不得窄于 `96px`，文字在其中居中。
- 所有选中态继续使用租户配置的选中背景色、文字色和图标色，不改变用户自定义配色逻辑。
- 键盘焦点样式和减少动态效果设置继续保留。

## 完成状态

- 最近学习卡片以接口返回的 `progressPercent >= 100` 判断课程已完成。
- 未完成课程继续显示播放图标和“继续学习”链接。
- 已完成课程不再显示“继续学习”，改为绿色圆形勾选图标与“已完成”状态胶囊。
- 已完成状态仅用于展示，不新增操作，课程进度条继续显示 100%。

## 组件边界

- `course.css` 与 `responsive.css` 负责统一三个选中控件的高度、内边距、圆角和最小宽度。
- `RecentCourseCard` 只负责根据完成状态切换尾部操作区展示。
- `learnerCourses` 提供可测试的最近学习完成状态判断，避免在组件内重复业务条件。
- 不修改后端接口、数据库结构、H5 布局或租户配色数据。

## 数据与异常处理

- 进度值经过现有 API 映射约束在 `0–100`；完成判断仍防御性使用 `>= 100`。
- 无效或缺失进度继续按 `0` 处理，展示“继续学习”，不误报完成。
- 完成标志使用语义化文本“已完成”，不依赖颜色单独传达状态。

## 验证标准

- 样式测试验证三类选中控件均为 `40px` 高、`10px` 圆角，课程详情标签最小宽度为 `96px`。
- 单元测试验证 `100` 及以上为已完成，`0–99` 为未完成。
- PC 现有测试和生产构建全部通过。
- 手工检查 1440px 与常见窄屏宽度下，无文字截断、跳动或横向溢出。
