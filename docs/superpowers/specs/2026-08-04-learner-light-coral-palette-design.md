# 学院端浅色红系配色设计

## 目标

修复学院端浅色页面中文字对比度不足的问题，并按用户选定的参考图统一 PC 与 H5 配色。页面结构、数据内容和交互流程保持不变。

## 配色

- 页面背景：白色与极浅灰，避免深色主题变量继续影响学院端。
- 卡片：白色背景、浅灰边框，保留轻量层次，不使用厚重阴影。
- 主标题和课程名称：深黑灰，保证在白色背景上清晰可读。
- 说明、数量和课时信息：中灰，和正文形成明确层级。
- 主要强调色：珊瑚红，参考图中的导航选中态、标签和进度色。
- 弱强调背景：极浅红，用于标签或轻量状态提示。
- 课程无封面时：使用珊瑚红色块与白色图标；真实课程封面不做调色处理。

建议色值：

| 用途 | 色值 |
| --- | --- |
| 主色 | `#ff5156` |
| 主色悬停 | `#e84349` |
| 主色浅背景 | `#fff1f0` |
| 标题/课程名称 | `#262626` |
| 正文 | `#595959` |
| 辅助文字 | `#8c8c8c` |
| 页面背景 | `#fafafa` |
| 卡片背景 | `#ffffff` |
| 边框 | `#eeeeee` |

## 范围

- PC：顶部品牌区、我的课程标题区、课程卡、课程详情、章节目录与学习页。
- H5：顶部区域、课程列表、课程详情、课时列表与学习页。
- 登录与机构选择继续使用现有租户品牌能力；登录后的学院学习界面采用统一红系配色。

## 验收标准

- 白色或浅灰背景上的标题、课程名和正文不再出现白色或低对比度文字。
- PC 与 H5 的主色、正文层级、卡片背景和边框一致。
- 页面仍保持当前简化后的信息结构，不新增统计卡、筛选栏或学习进度推断。
- 键盘焦点、悬停和选中状态清晰可见。
- 现有课程加载、进入详情和进入课时的交互保持正常。
