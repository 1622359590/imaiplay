# 登录页仅展示邮箱设计

## 目标

在手机号登录问题解决前，避免用户在登录页尝试手机号。后台、PC 学员端和 H5 学员端的账号字段统一只展示邮箱登录。

## 范围

- 后台登录页：字段标题改为“邮箱”，占位符只显示 `name@company.com`，使用邮箱格式校验。
- PC 学员登录页：字段标题改为“邮箱”，占位符只显示 `name@company.com`，使用邮箱格式校验。
- H5 学员登录页：占位符改为“邮箱”，使用邮箱格式校验。
- 登录提交仍沿用现有 `identifier` 参数和接口，不修改认证协议。

## 不在范围内

- 不删除后端手机号登录代码，便于修复后重新开放。
- 不调整用户资料、租户注册或手机号字段。
- 不调整当前基于手机号验证码的找回密码流程。
- 不调整短信配置和短信测试功能。

## 错误处理

空值继续显示必填提示；格式不符合邮箱规则时，三个登录页分别在提交前提示输入有效邮箱，不向登录接口发送手机号或其他非邮箱内容。

## 验证

- 自动测试覆盖三个登录页不再出现“手机号”及手机号示例。
- 自动测试覆盖邮箱格式校验配置。
- 运行后台、PC、H5 的测试与生产构建。
